# Keeping up with Agents

**AI moves fast. Keep up.**

An AI-narrated podcast navigating the field's live arguments, built from verified
wikis of major AI events' talks: who is on each side of every real disagreement,
the variable that explains the split, and what a technical product manager would
do about it. By [Clay Waters](https://www.linkedin.com/in/claywaters).

**Feed:** https://claywaters13.github.io/keeping-up-with-agents/feed.xml

Listen on Spotify / Apple Podcasts: links coming after directory approval.

Season 1 draws on the [AI Engineer World's Fair 2026 wiki](https://github.com/claywaters13/aiewf-2026-wiki):
231 talks, almost a million words, every quote verified verbatim against the source
video. Hosts are AI-generated (Google NotebookLM); every episode discloses this.

New episodes: `python3 scripts/add_episode.py <audio> --slug episode-NNN --title "..." --description "..."` then push.
